# 학습 계획

기준일: 2026-10-24. 순서와 편수는 작성하며 조정한다. 구분: **적용** = 실제 코드에서 사용 확인(pdps-tech-blog `docs/code-evidence.md` 기준, 2026-09-29 정적 검토), **확장** = 코드 적용 미확인, 학습·실험 목적.

## 1단계: 기초 도구와 조회

| 순서 | 구분 | 주제 | 핵심 질문 |
| --- | --- | --- | --- |
| 1 | 적용 | 시간·공간 복잡도 | 입력이 늘 때 비용을 어떻게 예측하고 측정하는가? |
| 2 | 적용 | 해시 테이블 | 순차 탐색과 해시 인덱스의 조회·메모리 비용은 어떻게 다른가? |
| 3 | 적용 | 이진 탐색 | 정렬·중복·경계 포함 규칙을 어떻게 처리하는가? |

## 2단계: 그래프

| 순서 | 구분 | 주제 | 핵심 질문 |
| --- | --- | --- | --- |
| 4 | 적용 | 방향 그래프 | 의존 관계를 어떤 구조로 저장하는가? |
| 5 | 적용 | DFS와 순환 탐지 | 방문 중·완료 상태를 왜 구분하는가? |
| 6 | 적용 | 위상 정렬 | 의존 순서로 실행하려면 어떻게 하는가? |

## 3단계: 큐와 캐시

| 순서 | 구분 | 주제 | 핵심 질문 |
| --- | --- | --- | --- |
| 7 | 적용 | LRU | 열린 자원 수에 한계가 있을 때 무엇을 내보낼 것인가? |

## 4단계: 시계열·스트림 확장 (후보)

| 구분 | 주제 | 핵심 질문 |
| --- | --- | --- |
| 확장 | 시계열 다운샘플링(min-max, LTTB) | 대용량 데이터를 차트에 그릴 때 어떻게 줄일 것인가? |
| 확장 | 문자열 탐색(KMP, Aho-Corasick) | 바이트열에서 동기 패턴 탐색은 어떻게 비교하는가? |
| 확장 | 링 버퍼·슬라이딩 윈도우 | 스트림에서 최근 N개를 일정 메모리로 다루는가? |
| 확장 | 유니온 파인드 | 연결 요소를 어떻게 묶는가? |

## 공통 기준

- 각 편: 작은 예제 손 추적 → 직접 구현 → 비교 실험 → 실패 조건.
- 적용 구분은 사실 확인 후 표기하고, 확인하지 않은 적용을 단정하지 않는다.
- 성능 수치는 측정 조건(입력 크기, 환경, 반복 횟수)과 함께 기록한다.
